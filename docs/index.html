FreeEgg AI

一个 Base URL，接入主流大模型 · 零依赖 · 原生 TypeScript

一个兼容 OpenAI / Anthropic / Gemini / Ollama 四套协议的网关， 用 Node 内置模块写成，没有一行第三方依赖，也不需要构建。 直接跑 .ts，因为 Node 22.18+ 自带类型擦除。

跑起来

docker run -d --name freeegg -p 8841:8841 \
  ghcr.io/mo-cn/fake-ai-api:latest

然后打开 http://127.0.0.1:8841/ —— 页面会按你的设备指纹签发一把 sk-fe-... 密钥， 把它和 Base URL http://127.0.0.1:8841/v1 填进任意 agent 客户端即可。

也可以用 docker compose：docker compose up -d。 想直接跑源码，本机装 Node 22.18+ 后执行 node src/index.ts。

为什么 API 不部署在这里

GitHub Pages 只能托管静态文件，没有 Node 运行时，也接不了动态请求。 所以这一页只是项目介绍，真正的服务请用上面的 Docker 命令在本地或你自己的服务器上跑起来。 镜像由 GitHub Actions 自动构建并推送到 GHCR。
